# EduVerse AI

EduVerse AI is an AI-powered learning platform designed to deliver personalized education, career guidance, and accessible learning experiences.

## Features

* Personalized Learning Dashboard
* AI Mentor Assistance
* Skill Tree Progression
* Career Roadmaps
* Teacher Analytics
* Accessibility-Focused Design

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Radix UI
* Material UI
* Recharts

## Live Demo

https://eduverse-fawn.vercel.app/

## Vision

To create an inclusive, adaptive, and career-oriented learning ecosystem that helps every learner achieve their full potential.
